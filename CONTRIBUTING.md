# Contributing

Bug reports, reproducible compatibility cases, and documentation corrections
are welcome through GitHub Issues.

To preserve the project's ability to offer both an open-source Free edition
and a separately licensed Pro edition, code pull requests are not accepted
until the project publishes a contributor license agreement workflow. Please
open an issue before writing code so ownership and licensing are explicit.

Never include typed text, license keys, tokens, certificates, private logs, or
personal information in an issue or diagnostic attachment.
